How unique IDs & passcodes work: every code you create gets a random unique ID — that ID is what the Data Matrix image actually encodes, so scanning it reveals the ID, not your secret message. Each ID has a passcode and may have an owner (or none at all). Anyone can look up an ID to see whether it has an owner, but to change the ID's message, owner, style or passcode you must enter the correct passcode — wrong passcodes are rejected (and rate-limited after repeated tries).
